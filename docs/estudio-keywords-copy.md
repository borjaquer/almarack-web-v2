## 2. Dudas que tiene el cliente antes de contratar → dónde se responden

1. ¿Es obligatoria la inspección? ¿Cada cuánto? ¿Quién puede hacerla? → normativa + inspección
2. ¿Cuánto cuesta? → cada servicio explica qué determina el precio y cómo se presupuesta (sin cifras inventadas)
3. ¿Tengo que parar el almacén o vaciar la estantería? → hero + cada servicio
4. ¿Qué me pide la Inspección de Trabajo / mutua / aseguradora? → guía PRSES + inspección
5. ¿Qué pasa si no lo hago? → normativa (sanciones y responsabilidad)
6. ¿Trabajáis con mi marca? → todas las páginas de servicio
7. ¿Cuánto tardáis en venir y en entregar el informe? → hero + inspección + cobertura
8. ¿Puedo revisar yo mismo la estantería? ¿Con qué checklist? → nueva página checklist
9. ¿Qué diferencia hay entre revisión interna e inspección experta? → guía PRSES + checklist
10. ¿Reparáis o solo vendéis? → «Técnicos, no vendedores»
